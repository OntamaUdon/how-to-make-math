# 加群論

## ベクトル空間の「係数」を、体から環へ広げる

線形代数のベクトル空間は「体（$\mathbb R$ や $\mathbb C$）の上の」空間でした。スカラー倍の係数が
体だったからこそ、基底がとれ、次元が定まり、話が綺麗だった。では、係数を体でなく
**環**（$\mathbb Z$ など、割り算ができないかもしれない世界）にしたら何が起こるか？

これが加群です。ベクトル空間の一般化ですが、係数の割り算が効かないぶん、
基底が取れないこともあり、ずっと豊かで繊細になります。ご褒美は絶大で、
**「$\mathbb Z$ 上の加群 ＝ アーベル群」「$K[x]$ 上の加群 ＝ 線形変換のついたベクトル空間」**と、
別々に見えた対象が一つの理論に統一される。線形代数のジョルダン標準形も、有限アーベル群の分類も、
実は同じ「PID上の加群の構造定理」の二つの顔なのです。

> 加群 ＝ 環の上のベクトル空間。線形代数と群論を一つの言葉にまとめ上げる。

## この分野の地図

1. **加群の基本** — 部分加群・剰余加群、準同型定理・直和直積、自由加群と基底・普遍性
2. **構造定理** — PID上有限生成加群の構造定理、ねじれ部分と自由部分、単因子形・初等因子形
3. **テンソルと完全性** — テンソル積の構成と普遍性、係数拡大、短完全系列と分裂、蛇の補題・五項補題
4. **加群の特殊類** — 射影加群・入射加群・平坦加群
