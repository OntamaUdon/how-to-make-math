# 第8章 連続と同相

## 位相空間にとっての「連続」と「同じ形」

距離を捨てた今、「連続」をどう定義するか。答えは第3章で用意してありました——
**開集合の逆像が開集合**。$\varepsilon$-$\delta$ は距離が要りましたが、この形は開集合さえあれば意味をもつ。
だから位相空間では、これを連続の“正式な定義”に据えます。

そして連続写像がそろえば、「位相の世界で同じ形」＝**同相**が定義できます。ドーナツとコーヒーカップが
「同じ」というあの有名な話（→[位相幾何学](/algebraic-topology)）の、正確な意味がここで与えられます。
伸ばす・曲げるは許すが、切る・貼るは許さない——そういう変形で移り合うものを同じとみなす。
その「同じ」を見抜く手がかりが、位相不変量です。

> 連続 ＝ 開集合の逆像が開。同相 ＝ 連続な全単射で逆も連続。位相の世界での「同じ形」。

## 連続写像

<Statement kind="definition" title="連続写像">
位相空間の間の写像 $f:X\to Y$ が<Term>連続</Term>とは、任意の開集合 $V\subseteq Y$ に対し
逆像 $f^{-1}(V)$ が $X$ の開集合であること。（同値：任意の閉集合の逆像が閉。）
</Statement>

距離空間ではこれが $\varepsilon$-$\delta$ と一致しました（[第3章](/set-topology/3)）。抽象化しても、
連続の直感「近くは近くへ移る」は保たれています。基や近傍で言い換えることもでき、実際の判定では
「基の要素の逆像が開かを見れば十分」など、手軽な形が使えます。

<Statement kind="proposition" title="連続の基本性質">
連続写像の合成は連続。恒等写像は連続。前章のコンパクト性・連結性（次章以降）は連続写像で像へ引き継がれる。
</Statement>

## 同相：位相的に「同じ」

<Statement kind="definition" title="同相写像">
全単射 $f:X\to Y$ が、$f$ も逆 $f^{-1}$ も連続のとき<Term>同相写像</Term>といい、$X$ と $Y$ は<Term>同相</Term>という。
同相な空間は、位相の立場では**まったく同じ**とみなす。
</Statement>

「全単射で、両方向が連続」がポイント。$f$ が連続でも $f^{-1}$ が連続とは限らないので、両方要ります。
同相はゴム膜のように連続変形（伸縮・曲げ）で移り合う関係で、切ったり貼ったりは含みません。

<Statement kind="example" title="同相なもの・そうでないもの">
開区間 $(0,1)$ と $\mathbb R$ は同相（$\tan$ で移り合う。長さは違っても位相は同じ）。
コーヒーカップとドーナツ（トーラス）は同相（穴1つどうし）。
だが円周 $S^1$ と区間 $[0,1]$ は同相でない、球面 $S^2$ とトーラスも同相でない——**穴の数が違う**から。
</Statement>

## 位相不変量：同相を見分ける道具

「2つが同相だ」は写像を1本作れば示せますが、「同相でない」を示すのは大変です（あらゆる写像の
不存在を言わねばならない）。そこで**同相なら必ず一致する量**を用意し、それが食い違えば
「同相でない」と結論します。

<Statement kind="definition" title="位相不変量">
同相写像で保たれる性質・量を<Term>位相不変量</Term>という。例：連結性、コンパクト性、
「穴の数」に対応する基本群やホモロジー（→[位相幾何学](/algebraic-topology)）、ハウスドルフ性など。
</Statement>

区間 $[0,1]$ は「1点を抜くと2つに分かれる」が、円周 $S^1$ は「1点を抜いてもつながったまま」。
この“連結性”の違いが不変量として効き、両者は同相でないと分かる。位相幾何学は、この
「不変量で形を区別する」戦略を、代数的な不変量（群・環）まで押し進めた分野です。

## 開写像・閉写像

連続は「逆像」の言葉でした。今度は「順像（像）」に注目した別種の良い写像です。

<Statement kind="definition" title="開写像・閉写像">
$f:X\to Y$ が<Term>開写像</Term>：任意の開集合の像 $f(U)$ が開。<Term>閉写像</Term>：任意の閉集合の像が閉。
</Statement>

連続（逆像で開が保たれる）とは独立の性質です。実は「連続な全単射＋開写像 ⇔ 同相」——
逆写像 $f^{-1}$ の連続性は、$f$ が開写像であることと同じなのです。この視点は、商写像（次章）や
[関数解析](/functional-analysis)の**開写像定理**（全射な有界線形作用素は開写像）で重要になります。

<Statement kind="remark" title="連続な全単射でも同相とは限らない">
$f:[0,2\pi)\to S^1,\ t\mapsto(\cos t,\sin t)$ は連続な全単射だが、逆は不連続（$0$ 付近で切れ目が生じる）。
だから同相ではない。「全単射かつ連続」だけでは足りず、逆の連続性（＝開写像であること）が要る好例。
ただし**コンパクト空間からハウスドルフ空間への連続な全単射は自動的に同相**（次章・第11章で回収）。
</Statement>

## つまずきポイント

<Statement kind="remark" title="よくある誤解">
- **連続は「逆像」、開写像は「順像」。** 混同しやすいが別物。同相には両方（連続かつ開写像＝逆も連続）が要る。
- **同相でないことは、不変量の食い違いで示す。** 写像が作れないことを直接言うのは難しい。
- 「連続な全単射 ⇒ 同相」は一般には偽。コンパクト＋ハウスドルフなど追加条件で初めて成り立つ。
</Statement>

## この章のまとめ

- **連続 ＝ 開集合の逆像が開**（$\varepsilon$-$\delta$ の距離ぬき版）。合成で保たれ、コンパクト性・連結性を像へ運ぶ。
- **同相**は「連続な全単射で逆も連続」＝位相的に同じ形。切らずに変形して移り合う関係。
- 同相でないことは**位相不変量**（連結性・穴の数など）の食い違いで示す。**開写像・閉写像**は順像に注目した性質で、逆写像の連続性と結びつく。

次章は、既存の空間から新しい位相空間を作る3つの標準操作——**部分空間・積・商**を扱います。
