# 集合と位相

## 「近い」を、距離を使わずに定義できるか

微積分では「$x$ が $a$ に近づく」を $\varepsilon$-$\delta$ で語りました（[微分積分学 第1章](/calculus/1)）。
そこでは「距離 $|x-a|$」が主役でした。でも、もっと抽象的な空間——関数の集まりや、
図形そのもの——には、自然な距離が無いこともあります。それでも「近い」「連続」「収束」を
語りたい。距離という具体を捨てて、**「近さ」の本質だけ**を取り出せないか?

その答えが位相です。「開集合」という“近さの器”を指定するだけで、距離が無くても連続・収束・
コンパクトが定義できる。この抽象化のおかげで、解析・幾何・代数のあらゆる空間を同じ言葉で
扱えるようになります。さらに土台の集合論では、「無限にも大小がある」（カントールの対角線論法）
という衝撃の事実や、証明に不可欠な選択公理を整えます。すべての分野の共通の地面です。

> 「距離」を捨てて「開集合」だけで近さを語る。無限の大小を測る集合論がその土台。

## この分野の地図

1. **集合の基礎** — 濃度・全単射による比較、可算/非可算、カントールの対角線論法、ベルンシュタインの定理、選択公理・ツォルンの補題
2. **距離空間** — 開・閉・閉包・内部、収束と連続、完備性・完備化・ベールのカテゴリー定理、コンパクト性（ハイネ–ボレル）、バナッハの不動点定理
3. **位相空間** — 開集合系・近傍・基、連続と同相・位相不変量、部分/積/商位相、分離公理（ハウスドルフ）、ウリゾーンの補題、連結性・チコノフの定理

## 前提

[微分積分学](/calculus)（$\varepsilon$-$\delta$）に触れていると「なぜ抽象化するのか」が腑に落ちます。
