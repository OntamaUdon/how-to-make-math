# 数理論理学・数学基礎論

## 数学が、自分自身を調べ始める

これまでの分野は「数学を使って」何かを調べてきました。数理論理学は、視線を反転させます。
**「証明する」「正しい」「計算する」という営みそのものを、数学の対象として調べる**のです。

すると、めまいのするような問いが立ち上がります。「正しいこと」は「証明できること」と一致するのか
（→ゲーデルの完全性定理：一階論理では一致する）。数学は自分の無矛盾性を自分で証明できるのか
（→不完全性定理：できない）。何が「計算可能」で、何が原理的に計算不能なのか（→停止性問題）。
連続体仮説は真か偽か（→どちらでもない、証明も反証もできない）。
数学の可能性と限界を、数学自身の手で描き出す——最も哲学的で、最もスリリングな分野です。

> 証明・真理・計算を数学の対象にする。ゲーデルが示した「数学の限界」がその頂点。

## この分野の地図

1. **記号論理学** — 命題論理（健全性・完全性）、一階述語論理、タルシの充足、ゲーデルの完全性定理、コンパクト性、レーヴェンハイム–スコーレム、様相・直観主義論理
2. **証明論** — 自然演繹・シークエント計算、カット除去、**ゲーデルの不完全性定理**、ゲンツェンの無矛盾性証明
3. **モデル理論** — 初等同値・初等埋め込み、量化子消去、型・飽和モデル、安定性理論
4. **計算可能性理論** — チューリング機械、帰納的関数、停止性問題、帰納的可算集合、チューリング次数
5. **公理的集合論** — ZFC・順序数・基数、構成可能集合 L、連続体仮説（ゲーデル・コーエン）、強制法、巨大基数
6. **型理論・構成的数学** — 単純型付き/依存型λ計算、Curry–Howard対応、ホモトピー型理論、逆数学
