# Godotの使い方

## 「ゲームを作ってみたい」で止まっている人へ

ゲームを作りたい、と思ったことがある人はたくさんいます。
でも実際に作り始めた人は、その中のほんの一部です。

理由ははっきりしています。**最初の一歩の情報が、いちばん抜けている**からです。
入門記事を開くと、いきなり「Area2D を追加して `_physics_process` で移動処理を書きます」と始まる。
Area2D って何？ `_physics_process` って何？ そもそもこの画面のどこに何を書けばいいの？
——そこで手が止まる。あなたの能力の問題ではなく、案内の問題です。

この部は、そこを埋めるために書きました。

> **約束**：この12章を上から順に読み、書いてあるとおりに手を動かせば、
> 誰でも **自分のゲームを3本完成させて、インターネットに公開する** ところまで行けます。
> プログラミング経験は要りません。「変数」も「関数」も、この中で説明します。

## Godot とは何か（30秒版）

<Term>Godot</Term>（ゴドー）は、**無料のゲームエンジン**です。
ゲームエンジンとは、ゲームを作るのに必要な道具——絵を表示する、音を鳴らす、
当たり判定を取る、ボタンの入力を受け取る——を全部そろえた作業台のこと。

Godot の良いところを3つだけ挙げます。

- **完全に無料**。売上から何割か取られる、ということもありません（MITライセンス）。
- **軽い**。ダウンロードは百数十MB。インストール作業すら不要で、解凍して起動すれば動きます。
- **2Dが得意**。「まず1本完成させる」段階の人にとって、これが決定的に効きます。

この部では **2Dゲーム** に絞ります。3Dは楽しいですが、
最初の1本を完成させる確率を下げる要因（モデリング、ライティング、パフォーマンス）が
一気に増えるからです。まず「完成させる」経験を1回すること。これが何よりの近道です。

「途中まで作って放置」を一度もしないこと。それがこの部の設計方針です。

## 必要なもの

- **パソコン**（Windows / macOS / Linux のどれでも）。10年落ちでもだいたい動きます。
- **インターネット接続**（Godot本体のダウンロードと、最後の公開に使います）
- **時間**。1章あたり30分〜2時間くらい。全部で20時間ほどを見ておくと安心です。

要らないものも書いておきます。**お金・絵の才能・数学・プログラミング経験**、どれも要りません。
絵は最初は四角と丸で作ります（本気で言っています。第7章でそうします）。

## 読み方のコツ

- **順番に読んでください。** 後半の制作回は、前半の用語をそのまま使います。
- **写経してください。** コードは読むだけだと入りません。手で打つと、エラーが出ます。
  エラーが出るのは失敗ではなく、**エラーの読み方を覚える回**です。第3章でその読み方も扱います。
- **完璧を目指さないでください。** 1本目は「ダサいけど動く」で大成功です。

準備ができたら、[第1章：ゲームエンジンとGodot](/godot/1) へどうぞ。
