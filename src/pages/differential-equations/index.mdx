# 微分方程式

## 「今の変化の仕方」から「これからの姿」を復元する

物理も生物も経済も、法則はたいてい「**変化のしかた**」で書かれます。
速度は位置の変化、加速度は速度の変化、人口の増え方は今の人口に比例…。
つまり自然が私たちに教えてくれるのは、$y$ そのものではなく $y'$ や $y''$ との関係——微分方程式です。

そこで問いはこうなります。**変化の法則が分かっているとき、元の量 $y(t)$ を復元できるか？**
これは積分の壮大な一般化であり、「未来を計算する」という営みそのものです。

> まず「どんな形なら手で解けるか」を覚え、次に「解けなくても解は存在するのか」を保証し、
> 最後に「解を求めずに振る舞い（安定か発散か）を読む」定性理論へ進みます。

## この分野の地図

### 常微分方程式
1. **初等解法** — 変数分離・一階線形（積分因子）・完全形・ベルヌーイ・リッカチ
2. **存在と一意性** — リプシッツ条件、ピカールの逐次近似、解の延長・比較定理
3. **線形微分方程式** — 定数係数（特性方程式）、未定係数法・定数変化法、連立系と行列指数関数、ロンスキアン
4. **定性理論** — 平衡点・線形化、相図と安定性（固有値分類）、リアプノフの方法

### 偏微分方程式（初等）
5. **一階PDE** — 特性曲線法、準線形方程式
6. **二階線形PDE** — 楕円・放物・双曲の分類、波動（ダランベール）・熱・ラプラス方程式
7. **解法** — 変数分離、フーリエ級数・変換、グリーン関数入門
