# 可換環論・ホモロジー代数

## 「方程式の零点」と「環」を、同じものとして扱う土台

方程式 $f(x,y)=0$ の零点は図形（曲線）を描きます。一方、その方程式が生む多項式環という
代数的対象もある。**この図形と環が、実は同じ情報を持っている**——これが代数幾何学の魂で、
その辞書を精密に整備するのが可換環論です。「一点だけを拡大鏡で見る（局所化）」「有限性を保証する
（ネーター環）」「整数の $\sqrt{}$ 的な拡張（整拡大）」といった道具で、零点集合と環を自在に往復します。

もう一つの柱、ホモロジー代数は、「完全系列がどこで破れるか」を測る技術です。
系列がぴったりつながらない“ズレ”を Ext・Tor という不変量で捉える。この「ズレを測る」発想は、
[位相幾何学](/algebraic-topology) の穴の数え上げと同じ精神で、代数・幾何・数論を貫きます。

> 図形と環を同一視する辞書（可換環論）と、「ズレ」を測る技術（ホモロジー代数）。
