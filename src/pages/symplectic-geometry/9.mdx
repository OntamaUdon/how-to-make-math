# 第9章 概複素構造と両立計量

後半、大域シンプレクティック幾何に入ります。シンプレクティック形式 $\omega$ には距離がありませんでした
（第1章）。でも解析の道具を使うには、計量が欲しい。そこで $\omega$ と**両立する概複素構造 $J$** を選びます。
$J$ を通して $\omega(\cdot,J\cdot)=g$ という計量が生まれ、[複素幾何](/complex-geometry)の概複素構造と手を結ぶ。
決定的なのは、この $J$ は**可積分でなくてよい**（本物の複素多様体でなくてよい）こと。そのゆるさが、
第11章の擬正則曲線という強力な解析の道具を可能にします。$\omega$・$J$・$g$ の三者が織りなす舞台を用意します。

## 両立する概複素構造

[複素幾何](/complex-geometry)で、概複素構造 $J$（$J^2=-1$、各点で「$i$ を掛ける」）を学びました。それを
シンプレクティック形式と“調和”させます。

<Statement kind="definition" title="ω と両立する概複素構造">
シンプレクティック多様体 $(M,\omega)$ の概複素構造 $J$（$J^2=-\mathrm{id}$）が $\omega$ と<Term>両立する</Term>
とは、
1. $\omega(JX,JY)=\omega(X,Y)$（$J$ が $\omega$ を保つ）、
2. $g(X,Y):=\omega(X,JY)$ が正定値（リーマン計量になる）。

を満たすこと。このとき $(\omega,J,g)$ が調和し、$M$ は<Term>概ケーラー多様体</Term>になる。
</Statement>

[複素幾何](/complex-geometry)第5章の三位一体 $\omega(X,Y)=g(JX,Y)$ と同じ関係が、ここでも成り立ちます。
違いは向き——複素幾何では計量 $g$ と $J$（可積分）から $\omega$ を作りましたが、シンプレクティックでは
$\omega$ が先にあり、それに合わせて $J$（と $g$）を選ぶ。$\omega$・$J$・$g$ のうち二つを決めれば三つ目が
決まる、という関係は同じです。

## 両立する J は必ず存在し、しかも本質的に一つ

両立する $J$ が選べるか、選び方に恣意性はないか——これが解析の道具として使うための要点です。答えは
「必ず存在し、選択に本質的な曖昧さはない」。

<Statement kind="theorem" title="両立する J の空間は可縮">
任意のシンプレクティック多様体で、$\omega$ と両立する概複素構造 $J$ は**必ず存在**する。さらに、両立する $J$
全体の空間 $\mathcal J(\omega)$ は**可縮**（一点に連続的に縮められる）。
</Statement>

<Statement kind="proof">
（骨子）任意にリーマン計量 $g_0$ を取り、$\omega$ と $g_0$ から作る歪対称作用素を極分解すると、$\omega$ と
両立する $J$ が標準的に得られる（存在）。この構成は $g_0$ に連続的に依存し、計量の空間が凸（可縮）なので、
$\mathcal J(\omega)$ も可縮。
</Statement>

**可縮**であることが決定的です。「$J$ の選び方に本質的な自由度がない」ので、$J$ を選んで定義した不変量
（第11章のグロモフ–ウィッテン不変量・フレアーホモロジー）は、実は $J$ の選び方に**よらない**——ホモトピーで
繋がっているから。恣意的に見える $J$ の選択が、最終的な不変量には影響しない。この事実が、$J$ を「計算の
ための補助道具」として自由に使うことを許します。第10・11章の剛性の議論は、この $J$ の存在と可縮性の上に
成り立っています。

## 可積分でなくてよい、というゆるさ

ここで、シンプレクティックと[複素幾何](/complex-geometry)の決定的な違いが現れます。

<Statement kind="remark" title="ケーラーとの関係・ずれ">
- **ケーラー多様体**（[複素幾何](/complex-geometry)）＝$\omega$・$J$・$g$ が両立し、**かつ $J$ が可積分**
  （ニューランダー–ニーレンバーグ、本物の複素多様体）。
- **概ケーラー**（本章）＝両立するが $J$ は可積分**でなくてよい**。$d\omega=0$ は課すが $J$ の可積分性
  （$N_J=0$）は課さない。

シンプレクティック幾何は、この「$J$ が可積分でなくてよい」ぶんケーラーより**広い**。多くのシンプレクティック
多様体はケーラー計量を持たない（第10章以降の主対象）。だが両立する $J$ はいつでも取れるので、複素幾何の
解析（$\bar\partial$、正則曲線）を“概”版として持ち込める。この絶妙なゆるさが後半の鍵。
</Statement>

$J$ を可積分に取れれば[ケーラー多様体](/complex-geometry)——複素幾何の豊かなホッジ理論が使えます。しかし
一般のシンプレクティック多様体では $J$ を可積分にできない。それでも「概」複素構造 $J$ は取れるので、
$J$-正則な曲線（第11章）という一次元的な正則対象は定義できる。**可積分性を諦める代わりに、曲線という
低次元の正則対象で解析を回す**——これがグロモフの革命的なアイデアで、次章以降で開花します。

<Statement kind="remark" title="つまずきポイント">
- **$\omega$ が先、$J$ は後から選ぶ**。複素幾何は $J$（可積分）が主役だが、シンプレクティックは $\omega$ が
  主役で $J$ は補助。$\omega(\cdot,J\cdot)=g$ で計量を借りる。
- **$J$ は可積分でなくてよい**。ここがケーラーとの分かれ目。概ケーラー ⊋ ケーラー。可積分性を課さない
  ゆるさが擬正則曲線を可能にする。
- **$J$ の空間が可縮 → 不変量が $J$ によらない**。補助的に選んだ $J$ の恣意性が、最終的な不変量には
  効かない。だから安心して $J$ を使える。
</Statement>

## この章のまとめ

- シンプレクティック形式に**両立する概複素構造 $J$**（$J^2=-1$、$\omega(JX,JY)=\omega(X,Y)$、
  $g=\omega(\cdot,J\cdot)>0$）を選ぶと、計量 $g$ が生まれ**概ケーラー多様体**になる。$\omega,J,g$ は三位一体。
- 両立する $J$ は**必ず存在**し、その空間は**可縮**。ゆえに $J$ で定義した不変量は $J$ の選び方によらない
  （補助道具として自由に使える）。
- ケーラー（[複素幾何](/complex-geometry)）と違い、$J$ は**可積分でなくてよい**。概ケーラー ⊋ ケーラーで、
  シンプレクティックは広い。可積分性を諦める代わりに、正則**曲線**で解析する道が開ける。

次章は、この $J$ と計量を武器に、シンプレクティック幾何の最も驚くべき大域現象——**グロモフの非圧縮定理**を
見ます。体積では説明できない、シンプレクティック特有の「剛性」の発見です。
