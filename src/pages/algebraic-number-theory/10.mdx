# 第10章 類数の有限性

前章のミンコフスキーの定理を、いよいよ数論に効かせます。定理を定量化すると、「**どのイデアル類にも、ノルムが
ある限界以下の代表イデアルがある**」という命題が出ます。ノルムが有界なイデアルは有限個しかないので、
イデアル類も有限個——**イデアル類群は有限群**。第8章で残した問い「類群は有限か」に、幾何が決着をつけます。
しかもこの限界（ミンコフスキー限界）は、類数を実際に計算する道具にもなります。

## ミンコフスキー限界：小さな代表の存在

まず、各イデアルの中に「ノルムの小さい元」が必ず取れることを、ミンコフスキーの定理から引き出します。

<Statement kind="theorem" title="ミンコフスキーの限界">
数体 $K$（次数 $n$、実埋め込み $r_1$ 個・複素埋め込み $r_2$ 組、判別式 $d_K$）の任意の $0$ でないイデアル $I$ は、
$$0\neq\alpha\in I,\qquad |N_{K/\mathbb Q}(\alpha)|\le M_K\cdot N(I)$$
を満たす元 $\alpha$ を含む。ここで<Term>ミンコフスキー定数</Term>は
$$M_K=\left(\frac{4}{\pi}\right)^{r_2}\frac{n!}{n^n}\sqrt{|d_K|}.$$
</Statement>

<Statement kind="proof">
（骨子）イデアル $I$ をミンコフスキー埋め込みで格子とみると、その共体積は $N(I)\sqrt{|d_K|}$ に比例。
$|N(\alpha)|\le c$ で定まる原点対称な凸領域（各座標の積が有界な集合）の体積を計算し、ミンコフスキーの定理の
閾値 $2^n\mathrm{covol}$ を超えるよう $c$ を選ぶと、その領域内に非零格子点 $\alpha\in I$ が取れる。$c$ の最小値が
$M_K\cdot N(I)$。前章の「体積が閾値を超えれば格子点あり」を、ノルムの評価に翻訳しただけ。
</Statement>

「イデアル $I$ の中に、ノルムが $M_K N(I)$ 以下の元がある」——前章の装置で見た「小さなノルムの元が必ず取れる」の
定量版です。判別式 $\sqrt{|d_K|}$ が限界に効くのも、それが格子の共体積だったから。この一つの不等式が、以下すべてを
生みます。

## 核心：イデアル類群は有限

<Statement kind="theorem" title="類数の有限性">
任意の数体 $K$ のイデアル類群 $\mathrm{Cl}(K)$ は**有限群**である。すなわち類数 $h_K<\infty$。さらに、すべての
イデアル類は、ノルムが $M_K$ 以下のイデアルで代表される。
</Statement>

<Statement kind="proof">
任意のイデアル類 $[I]$ を取る。逆類の代表 $J$（$[J]=[I]^{-1}$）に対し、ミンコフスキーの限界で
$0\neq\alpha\in J$、$|N(\alpha)|\le M_K N(J)$ を取る。$\alpha\in J$ より $(\alpha)\subseteq J$、すなわち
$(\alpha)=J\cdot I'$ となるイデアル $I'$ があり、$[I']=[J]^{-1}=[I]$。ノルムの乗法性から
$N(I')=|N(\alpha)|/N(J)\le M_K$。ゆえに**類 $[I]$ はノルム $\le M_K$ のイデアル $I'$ で代表される**。

ノルムが $M_K$ 以下のイデアルは有限個しかない（$N(I')=m$ なら $I'\supseteq(m)$ で、$\mathcal O_K/(m)$ は有限、
その部分加群も有限個）。よってイデアル類も有限個、$h_K<\infty$。
</Statement>

証明の心は二段です。**(1) ミンコフスキーで、どの類もノルム $\le M_K$ の代表を持つ**（幾何）。**(2) ノルムが
有界なイデアルは有限個**（$N(I)\le M_K$ の $I$ は、有限個の素イデアルの有限べきの積に限られる）。無限に見えた
イデアル類が、$M_K$ という有限の壁の中に全部収まる。第8章で「有限に収まるのは自明でない」と言った難所を、
幾何数論が正面から突破しました。

## 類数を計算する

ミンコフスキー限界は、類数を**手計算できる**アルゴリズムを与えます。手順はこうです。

<Statement kind="remark" title="類数の計算レシピ">
1. **ミンコフスキー定数 $M_K$ を求める**（$r_1,r_2,d_K$ から）。
2. **$M_K$ 以下の素数 $p$ を列挙**し、各 $p$ の素イデアル分解（第7章のデデキント判定法）でノルム $\le M_K$ の
   素イデアルを全部書き出す。これらが類群を生成する。
3. **生成元の間の関係**（どの積が単項か）を、ノルムの小さい元を探して決める。
4. 生成元と関係から**類群の構造**（と類数 $h_K$）を読む。
</Statement>

例：$K=\mathbb Q(\sqrt{-5})$。$r_1=0,r_2=1,d_K=-20$ で $M_K=\frac4\pi\cdot\frac{2!}{2^2}\sqrt{20}=\frac{2}{\pi}\sqrt{20}\approx2.85$。
だから $M_K$ 以下の素数は $2$ だけ調べればよい。$(2)=\mathfrak p_1^2$（第7章、$2$ は分岐）で、$\mathfrak p_1$ は
ノルム $2\le M_K$ の唯一の非自明素イデアル。$\mathfrak p_1$ は単項でなく（$N(\alpha)=2$ の元なし）、
$\mathfrak p_1^2=(2)$ 単項ゆえ位数 $2$。よって $\mathrm{Cl}(\mathbb Q(\sqrt{-5}))\cong\mathbb Z/2$、$h_K=2$。第8章で
主張した値が、今度は**有限個の素数を調べるだけで完全に決定**できました。

<Statement kind="remark" title="類数 1 の判定にも使える">
$M_K<2$ なら、調べるべき素数がなく、すべてのイデアルが単項＝$h_K=1$。たとえば $\mathbb Q(\sqrt{-1})$（ガウス整数、
$d_K=-4$、$M_K=\frac4\pi\approx1.27<2$）、$\mathbb Q(\sqrt{-3})$ などは $M_K<2$ で即座に PID と分かる。虚二次体で
$h_K=1$ になるのは $d=-1,-2,-3,-7,-11,-19,-43,-67,-163$ の九個だけ（ガウスの類数 1 問題、ヘーグナー）。
</Statement>

<Statement kind="remark" title="つまずきポイント">
- **有限性の二本柱**：ミンコフスキー（小さい代表の存在）＋ノルム有界なイデアルの有限性。前者が幾何、
  後者が代数。両方要る。
- **$M_K$ は「調べる範囲」を与える**。$M_K$ 以下の素数だけで類群が生成される、という有限性が計算を可能にする。
  $M_K$ は判別式が大きいほど大きく、計算量が増える。
- **有限だが値は不規則**。$h_K$ は必ず有限でも、体ごとの値は非常に不規則で深い（虚二次体では $|d|$ とともに
  概ね増えるが、実二次体では $h_K=1$ が多いか無限かすら未解決）。有限性は易しく、値は難しい。
</Statement>

## この章のまとめ

- **ミンコフスキーの限界**：任意のイデアル $I$ に、$|N(\alpha)|\le M_K N(I)$ を満たす $0\neq\alpha\in I$ がある。
  $M_K=(4/\pi)^{r_2}\frac{n!}{n^n}\sqrt{|d_K|}$。前章の格子点定理の定量版。
- **類数の有限性**：どのイデアル類もノルム $\le M_K$ の代表を持ち、そのようなイデアルは有限個。ゆえに
  $\mathrm{Cl}(K)$ は**有限群**、$h_K<\infty$。第8章の問いに幾何が決着。
- **計算法**：$M_K$ 以下の素数の素イデアル分解を調べれば類群が決まる。$\mathbb Q(\sqrt{-5})$ は $M_K\approx2.85$ で
  $h_K=2$、$M_K<2$ の体（ガウス整数など）は即 $h_K=1$。

イデアル側（類群）の有限性が片付きました。残るのは**単数**側——$\mathcal O_K$ の可逆元 $\mathcal O_K^\times$ の
構造です。次章は**ディリクレの単数定理**で、単数群がどんな形をしているかを明らかにします。
