# GitHubとClaudeの使い方

## 「アップロードしたけど、これで何が変わったの？」

自分のPCのフォルダを GitHub に `git push` した。画面には `[new branch] main -> main` と出た。
成功したらしい。でも、**だから何が起きたのか**がよく分からない。

そう感じるのは自然です。`git push` の成功は、見た目には何も変わらないからです。
サイトが急に公開されるわけでも、ファイルが増えるわけでもない。

この部では、その「何が変わったのか」を3つの章で順に解き明かします。

## 3つの章

1. [GitHubの基本](/github-claude/1) — リポジトリ、コミット、ブランチ、push とは何か。操作できる図つき。
2. [Claudeにできること](/github-claude/2) — Claude は何を、どこで、どこまでやってくれるのか。できないことも正直に。
3. [PRとレビューの流れ](/github-claude/3) — Claude の変更を、安全に確認して取り込む手順。

## この部の読み方

- 上から順に読むのがおすすめです。各章は前の章の言葉を使います。
- 新しい言葉は、意味を説明してから名前を出します。分からなくなったら、その章の「ここまでのまとめ」に戻ってください。
- 登場する例は、すべてこのサイト（数学の作り方）のものです。
