# 数学の作り方

## この本は「答え」ではなく「なぜ」から始めます

教科書を開くと、いきなり定義があって、定理があって、証明がある。
一行ずつは追えるのに、読み終わると「で、これは結局なんだったの？」が残る——
数学でいちばん多いつまずきは、実はここにあります。

このサイトは、その順番をひっくり返します。
**まず「どんな困りごとがあって、人はこれを考えたくなったのか」**を作ってから、
直感 → 具体例 → そして最後に、その直感を正確に言い直したものとして定義や定理を置く。
「隣に座った友人が一緒に考えてくれる」——そういうトーンで書いています。

> 読者を賢いと信じます。でも、途中で置いていきません。
> 「ここ飛躍してない？」という感覚が出たら、それはこちらの負けです。

## 全体の地図

数学は大きく **解析・代数・幾何・基礎** の4つの大陸に分かれます。
どこから読んでもいいですが、多くの分野は下にいくほど前の分野を土台にします。
まずは **微分積分学** と **線形代数学** の2つが、ほぼすべての入り口です。

### 解析 — 「限りなく近づく」を厳密に扱う

- [微分積分学](/calculus) — 極限・微分・積分。すべての解析の土台。**（完成）**
- [複素解析](/complex-analysis) — 複素数で微分すると、驚くほど世界が綺麗になる
- [微分方程式](/differential-equations) — 変化の法則から未来を復元する
- [測度論・ルベーグ積分](/measure-theory) — 「面積」を測り直して積分を作り直す
- [関数解析](/functional-analysis) — 関数を「点」とみなす無限次元の線形代数
- [実解析・フーリエ解析](/fourier-analysis) — 波の重ね合わせで関数を分解する
- [確率論](/probability) — 偶然を測度論の言葉で厳密にする
- [偏微分方程式（発展）](/pde-advanced) — 熱・波・ポテンシャルの現代的な扱い
- [変分法](/calculus-of-variations) — 「いちばん良い形」を方程式にする

### 代数 — 「構造」だけを抜き出して調べる

- [線形代数学](/linear-algebra) — ベクトル・行列・固有値。もう一つの入り口。**（完成）**
- [群論](/group-theory) — 「対称性」そのものを数学にする
- [環論](/ring-theory) — 足し算と掛け算がある世界の整数論
- [体論・ガロア理論](/field-and-galois) — 方程式が解けるか否かを対称性で見抜く
- [加群論](/module-theory) — ベクトル空間を環の上へ一般化する
- [表現論](/representation-theory) — 抽象的な群を行列として「見える化」する
- [可換環論・ホモロジー代数](/commutative-homological) — 代数幾何と数論の共通言語
- [代数的整数論](/algebraic-number-theory) — 整数の世界を広げて素因数分解を取り戻す
- [非可換環・リー環](/noncommutative-lie) — 半単純環とリー環の構造論

### 幾何 — 「曲がった空間」の形を測る

- [多様体論](/manifolds) — 曲がった空間の上で微積分をやり直す
- [位相幾何学](/algebraic-topology) — 穴の数を代数で数える
- [微分幾何学](/differential-geometry) — 曲線と曲面の「曲がり具合」を測る
- [リー群](/lie-groups) — 連続的な対称性の群
- [リーマン幾何学](/riemannian-geometry) — 距離の入った多様体の幾何
- [代数幾何学](/algebraic-geometry) — 方程式の零点を図形として扱う
- [微分位相幾何学](/differential-topology) — 滑らかな写像で多様体を分類する
- [複素幾何学](/complex-geometry) — 複素数で座標を入れた多様体
- [シンプレクティック幾何学](/symplectic-geometry) — 古典力学の幾何

### 基礎 — 数学そのものを支える土台

- [集合と位相](/set-topology) — 「近い」とは何かを集合の言葉で定義する
- [数理論理学・数学基礎論](/logic-foundations) — 証明とは何か、を数学の対象にする
- [圏論](/category-theory) — 分野をまたいで「同じ形」を見つける言語

## 読み方

各分野のトップページは、その分野全体の**地図**になっています。
まず地図を眺めて景色を掴んでから、章に入ってください。
現在は **微分積分学** と **線形代数学** が本文まで完成しています。ほかの分野は地図と目次を用意し、順次本文を追加していきます。

準備ができたら、まずは [微分積分学](/calculus) か [線形代数学](/linear-algebra) から。
